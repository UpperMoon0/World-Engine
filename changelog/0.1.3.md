# World Engine 0.1.3

- Skip empty Sable holding-map ticks and saves when no lifecycle work or storage writes are pending.
- Avoid rewriting empty force-load ticket data solely because a dimension was saved; preserve dirty ticket removals and pointer updates.
- Flush cached sublevel files only after writes, keeping failed writes/flushes pending and preserving Sable's close-time force.
- Add paired stock-Sable dimension/save benchmarks and real-server restart, force-load, deletion, and storage regression checks.
- The [Windows dimension benchmark](../docs/benchmarks/2026-10-14-59cf28e/README.md) showed 54–79% lower idle-tick latency and 30–45% lower process CPU versus stock Sable, but 16–20% higher whole-world save latency. The comparison includes existing World Engine optimizations; it is not an overall performance claim.
